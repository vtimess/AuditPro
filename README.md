# 港审通 AuditPro

港务审计微信小程序与统一 FastAPI 后端。

## 当前开发范围

- 微信登录
- 角色化首页
- 工作台
- 个人中心
- 工时定位打卡
- 当月打卡日历、月份切换和缺卡补卡申请
- 公安备案人员录入、查询、修改、删除和 Excel 导出
- 耗材采购台账、人工总价调整、发票照片和 Excel 导出
- 安全检查、危险点、整改提交和复查闭环

工作台目前已开放“公安备案”“耗材采购”“安全检查”和“工时打卡”，其他模块按开发计划逐步开放。

## 项目目录

```text
AuditPro/
├── backend/        FastAPI 后端和 MySQL 初始化脚本
├── miniprogram/    微信原生小程序
├── app/            预留的 Web 系统管理端目录
└── 港务审计一体化平台设计方案.md
```

## 小程序运行

1. 使用微信开发者工具导入 `miniprogram` 目录。
2. AppID 已配置为 `wxaa5ec51c6c3a5d36`。
3. 本地联调时，在开发者工具中勾选“不校验合法域名”。
4. 本地联调接口默认指向 `http://127.0.0.1:8000/api/v1`。
5. 真机和正式发布前，将 HTTPS 后端域名添加到微信公众平台的 request 合法域名。

## 后端运行

详细说明见 `backend/README.md`。数据库密码和微信 AppSecret 必须通过服务器环境变量提供，不写入代码。
